🎯 Project Purpose

The Fatter Matter Calorie Tracker (FMCT) is an innovative IoT health tracking system designed to bridge physical hardware telemetry with cloud analytics. By utilizing an embedded barcode scanner, users can seamlessly scan food items to log caloric intake, sodium levels, and added sugars instantly without needing a cumbersome smartphone app.

🛠️ Parts & Tech Stack Used

  • Raspberry Pi Pico W: Microcontroller handling Wi-Fi connectivity and MicroPython code execution.
  • GM67 Barcode Scanner: Hardware module used to read food and beverage packaging barcodes.
  • Google Cloud Firestore: Cloud NoSQL database storing live RESTful records under `fmct_items`.
  • Firebase Authentication: Secure user management supporting email/password login and account creation.
  • Chart.js & GitHub Pages: Frontend web hosting and interactive data visualization for trend tracking.

💡 How It Helps People

Traditional calorie tracking apps require tedious manual searching through massive food databases. FMCT automates this friction point:

  • Reduces friction in logging daily meals using physical barcode scans.
  • Provides real-time visibility into cumulative dietary habits via auto-refreshing charts.
  • Empowers users to monitor nutritional intake trends over time effortlessly.

📖 User Instructions

  • Step 1: Create an account or log in through the burger authentication portal.
  • Step 2: Use the Raspberry Pi Pico W scanner to scan a food or beverage barcode.
  • Step 3: View the automatically updated daily nutrition trend graph and summary widgets live on your main dashboard!

🔥 Challenges I Faced

  • MicroPython REST APIs: Configuring `urequests` headers and payload formats to properly target Google Cloud Firestore REST endpoints over 2.4 GHz Wi-Fi.
  • Real-Time UI Synchronization: Implementing clean asynchronous data fetching loops and dynamic chart updates without lagging the web browser.
  • Responsive Theming: Balancing playful burger aesthetics with clean, professional dashboard layouts across mobile and desktop viewports.
